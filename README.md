# 地图定位工具 · Map Locator

🔗 在线使用：**https://map.luobei.org.cn**

一个**纯前端、照片不上传**的地图定位小工具。所有解析在浏览器本地完成，无需注册、免费无广告。

## 功能

- **经纬度定位**：输入坐标在地图查看位置；或在地图选点读取经纬度。支持十进制 / 度分秒自动识别，WGS-84 / GCJ-02 坐标系互转。
- **照片定位**：上传照片，本地读取 EXIF 中的 GPS 拍摄位置并在地图标记，同时显示拍摄时间、设备型号。
- **照片 GPS 编辑**：在线修改 / 清除 / 添加照片的 GPS 坐标（修正定位、发图前抹位置、给旅行照补位置标签）。
- **IP 定位**：输入 IPv4 查询归属城市并在地图标出。

## 技术栈

Vue 3 + TypeScript + Vite · 高德地图 JS API · exifr（EXIF 解析）· gcoord（坐标系转换）· piexifjs（EXIF 写入）· fflate（ZIP 解包）

## 隐私

照片全程在用户浏览器本地处理，不上传任何服务器。
